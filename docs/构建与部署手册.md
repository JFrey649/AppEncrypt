# AppEncrypt — 构建与部署手册

| 文档版本 | v1.1 |
|---------|------|
| 更新日期 | 2026-07-15 |

本文档说明：**环境准备 → 编译 → 生成 → 打包 → 安装 → 卸载** 的完整手动流程。

---

## 1. 环境要求

| 组件 | 版本/说明 |
|------|-----------|
| 操作系统 | Windows 10 1903+ / Windows 11（x64） |
| Visual Studio | 2022，含「使用 C++ 的桌面开发」 |
| CMake | 3.16+ |
| Qt | 6.x，组件：Core、Widgets（MSVC 2022 64-bit） |
| Inno Setup | 6.x（仅打包安装包时需要） |
| curl / tar | Windows 10+ 自带（fetch_sqlite.bat 使用） |

### 本机参考路径（请按实际安装位置修改）

```
CMake:     D:\Program Files\CMake\bin\cmake.exe
Qt:        D:\Qt\6.10.2\msvc2022_64
Inno Setup: D:\Program Files (x86)\Inno Setup 6\ISCC.exe
```

## 2. 首次准备

在项目根目录 `appEncrypt` 下打开 **命令提示符（cmd）** 或 **Developer Command Prompt**：

```bat
cd /d D:\JF\Proj\appEncrypt

REM 下载 SQLite amalgamation（仅首次或 third_party/sqlite 缺失时）
scripts\fetch_sqlite.bat
```

## 3. 编译（CMake 生成 + 构建）

### 3.1 删除 build 后重新生成

若已删除 `build` 文件夹，执行：

```bat
cmake -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="D:/Qt/6.10.2/msvc2022_64"
cmake --build build --config Release
```

若 `cmake` 不在 PATH 中：

```bat
"D:\Program Files\CMake\bin\cmake.exe" -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="D:/Qt/6.10.2/msvc2022_64"
"D:\Program Files\CMake\bin\cmake.exe" --build build --config Release
```

### 3.2 日常增量编译

代码修改后只需：

```bat
cmake --build build --config Release
```

### 3.3 编译产物

| 文件 | 路径 |
|------|------|
| 主程序 | `build\Release\AppEncrypt.exe` |
| 启动器 | `build\Release\AppEncryptStub.exe` |

> **注意：** `build\Release` 下直接双击 `AppEncrypt.exe` **可能因缺少 Qt DLL 而无法运行**。开发测试需先执行 `windeployqt`（见 4.2），或使用安装包安装。

### 3.4 Debug 编译（可选）

```bat
cmake --build build --config Debug
```

## 4. 生成可运行目录

### 4.1 一键打包（推荐）

```bat
scripts\build_installer.bat "D:\Qt\6.10.2\msvc2022_64"
```

脚本会自动：

1. 检查 `build\Release` 产物  
2. 创建 `dist\staging`  
3. 运行 `windeployqt` 复制 Qt 依赖  
4. 调用 Inno Setup 生成安装包  

### 4.2 仅生成 staging（不打包）

```bat
cmake --build build --config Release

mkdir dist\staging 2>nul
copy /Y build\Release\AppEncrypt.exe dist\staging\
copy /Y build\Release\AppEncryptStub.exe dist\staging\
"D:\Qt\6.10.2\msvc2022_64\bin\windeployqt.exe" dist\staging\AppEncrypt.exe --release --no-translations --dir dist\staging
```

然后可直接运行 `dist\staging\AppEncrypt.exe` 进行测试。

### 4.3 安装包输出

```
dist\AppEncrypt-Setup-1.0.0.exe    ← 分发给用户的安装程序
dist\staging\                      ← 中间目录（含 Qt DLL）
```

## 5. 打包（Inno Setup）

### 5.1 自动打包

```bat
scripts\build_installer.bat "D:\Qt\6.10.2\msvc2022_64"
```

可选参数（按顺序）：

| 位置 | 参数 | 默认 |
|------|------|------|
| 1 | QtDir | `D:\Qt\6.10.2\msvc2022_64` |
| 2 | AppVersion | `1.0.0` |
| 3 | Configuration | `Release` |
| 4 | IsccPath | 自动搜索 Inno Setup 6 |

### 5.2 手动调用 ISCC

```bat
scripts\build_installer.bat "D:\Qt\6.10.2\msvc2022_64" "1.0.0" Release "D:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

参数顺序：`QtDir` `AppVersion` `Configuration` `IsccPath`（后三项可省略）

安装脚本源文件：`installer\AppEncrypt.iss`

## 6. 安装

### 6.1 用户安装（推荐）

1. 双击 `dist\AppEncrypt-Setup-1.0.0.exe`  
2. 按向导完成（默认安装到 `C:\Program Files\AppEncrypt`）  
3. 安装程序自动执行：
   - 复制程序与 Qt 运行库  
   - 创建开始菜单快捷方式  
   - `register-shell --quiet` 注册 exe 右键菜单  

### 6.2 安装后目录结构

```
C:\Program Files\AppEncrypt\
├── AppEncrypt.exe
├── AppEncryptStub.exe
├── config.ini          ← 首次运行后生成/更新
├── appencrypt.db       ← 加密记录数据库
├── Qt6*.dll
├── platforms\
└── ...
```

全局备用配置：

```
C:\ProgramData\AppEncrypt\config.ini
```

### 6.3 绿色版手动部署（免安装包）

1. 将 `dist\staging\` 整个文件夹复制到目标路径  
2. 以管理员或普通用户运行：

```bat
cd /d "目标路径"
AppEncrypt.exe register-shell
```

## 7. 使用

### 7.1 图形界面

```bat
"C:\Program Files\AppEncrypt\AppEncrypt.exe"
```

### 7.2 右键菜单（安装后自动注册）

在任意 `.exe` 上右键：

- 使用 AppEncrypt 加密  
- 使用 AppEncrypt 解密  
- 更改 AppEncrypt 密码  

### 7.3 命令行

```text
AppEncrypt.exe encrypt   "D:\path\app.exe"
AppEncrypt.exe decrypt   "D:\path\app.exe"
AppEncrypt.exe changepw  "D:\path\app.exe"
AppEncrypt.exe register-shell
AppEncrypt.exe unregister-shell
```

## 8. 卸载

### 8.1 标准卸载（推荐）

**设置 → 应用 → 已安装的应用 → AppEncrypt → 卸载**

卸载程序自动执行：

1. `uninstall-restore --quiet` — 还原所有已加密 exe  
2. `unregister-shell --quiet` — 移除右键菜单  
3. 删除 `%ProgramData%\AppEncrypt`  
4. 删除安装目录  

卸载后，曾被加密的程序应可直接双击运行，**无需密码**。

### 8.2 手动卸载（未走安装包时）

若程序在 `C:\Program Files\AppEncrypt`：

```bat
cd /d "C:\Program Files\AppEncrypt"

REM 1. 还原所有加密程序
AppEncrypt.exe uninstall-restore

REM 2. 移除右键菜单
AppEncrypt.exe unregister-shell

REM 3. 手动删除安装文件夹
```

### 8.3 仅移除右键菜单

```bat
scripts\unregister_shell.bat "C:\Program Files\AppEncrypt"
REM 或
AppEncrypt.exe unregister-shell
```

## 9. 常见问题

| 问题 | 处理 |
|------|------|
| `cmake` 找不到 Qt | 检查 `-DCMAKE_PREFIX_PATH` 是否指向 `...\msvc2022_64` |
| 缺少 `sqlite3.c` | 运行 `scripts\fetch_sqlite.bat` |
| 双击 exe 提示缺 DLL | 对目录运行 `windeployqt`，或使用安装包安装 |
| 右键无菜单 | 运行 `AppEncrypt.exe register-shell` 或重装 |
| 卸载后 exe 仍要密码 | 以管理员重试卸载，或手动 `uninstall-restore` |
| 密码正确但程序不启动 | 确认使用最新版；查看弹窗错误码（740=需管理员，5=权限/杀软） |
| unlock 后同目录残留 `.appencrypt.run.exe` | 宿主异常退出未清理，可手动删除 |
| ISCC 找不到 | 安装 Inno Setup 6，或第 4 参数指定 ISCC 路径 |

## 12. 辅助脚本说明

| 脚本 | 用法 |
|------|------|
| `scripts\fetch_sqlite.bat` | 下载 SQLite amalgamation 到 `third_party\sqlite` |
| `scripts\build_installer.bat` | `[QtDir] [Version] [Config] [ISCC]` 一键 staging + 安装包 |
| `scripts\register_shell.bat` | `[InstallDir] [--system]` 注册右键菜单 |
| `scripts\unregister_shell.bat` | `[InstallDir] [--system]` 移除右键菜单 |
| `scripts\install_sendto.bat` | `<InstallDir>` 创建「发送到 → AppEncrypt 加密」 |
| `scripts\create_shortcut.vbs` | 由 install_sendto 调用，创建 .lnk |

`--system` 模式会通过 PowerShell 请求 UAC 提权（仅此场景依赖 PowerShell）。
