## 2. 技术决策（已实现）

### 2.1 技术栈

| 项目 | 决策 | 实现状态 |
|------|------|----------|
| SQLite | sqlite3 C API（`third_party/sqlite` amalgamation） | ✅ |
| 加密库 | Windows CNG（BCrypt）：PBKDF2 + AES-256-GCM | ✅ |
| DPAPI | 额外保护 DEK，供卸载无密码还原 | ✅ |
| 目标架构 | 仅 x64 | ✅ |
| 最低系统 | Windows 10 1903+ / Windows 11 | ✅ |
| 字符编码 | 源码 UTF-8（MSVC `/utf-8`），UI 字符串 UTF-8 | ✅ |

### 2.2 架构设计

| 项目 | 决策 | 实现说明 |
|------|------|----------|
| 密文存放 | 同目录 `{exe}.appencrypt` | `FileLayout::vaultPathFor` |
| 启动器 | 通用 Stub + PE 尾部配置块 v2 | 含 UUID、密文相对路径、launcher 绝对路径 |
| Stub UI | Stub 无 Qt，调用 `AppEncrypt.exe unlock` | `stub/stub_main.cpp` |
| 路径绑定 | 严格绝对路径 | DB `original_path` 唯一键 |
| 解密启动 | **同目录** `{uuid}.appencrypt.run.exe`，退出后删除 | 非 TEMP，保证 DLL 加载 |
| 工作目录 | 宿主 exe 原目录 | `ProcessUtil::launchAndWait` |
| 命令行参数 | 原样转发 | Stub → unlock → CreateProcess |
| 提权启动 | CreateProcess 失败 740 时 ShellExecute runas | `ProcessUtil` |

### 2.4 安全策略

| 项目 | 决策 |
|------|------|
| 密码最小长度 | 6 位 |
| 密钥派生 | PBKDF2-HMAC-SHA256，100,000 次 |
| 对称加密 | AES-256-GCM |
| 数据库存储 | salt + password_verifier + wrapped DEK，不存明文密码 |
| DPAPI | 保护 DEK 副本，卸载还原用 |

## 4. 可执行文件职责

| 二进制 | 职责 |
|--------|------|
| `AppEncrypt.exe` | GUI + CLI + unlock + 卸载还原 + Shell 注册 |
| `AppEncryptStub.exe` | 加密时复制为宿主名；双击 → 调主程序 unlock |

> 无独立 `uninstall.exe`；卸载逻辑集成于主程序 `uninstall-restore`。

---

## 5. CLI 接口

```
AppEncrypt.exe encrypt   "<exe_path>"
AppEncrypt.exe decrypt   "<exe_path>"
AppEncrypt.exe changepw  "<exe_path>"
AppEncrypt.exe unlock    "<stub_path>" [host_args...]
AppEncrypt.exe uninstall-restore [--quiet]
AppEncrypt.exe register-shell   [--system] [--quiet]
AppEncrypt.exe unregister-shell [--system] [--quiet]
```
